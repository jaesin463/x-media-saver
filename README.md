# X 미디어 저장기

## Windows 설치

[최신 설치 파일](https://github.com/jaesin463/x-media-saver/releases/latest/download/XMediaSaverSetup.exe)인 `XMediaSaverSetup.exe`를 실행하세요. Windows 10/11 x64와 Microsoft Edge WebView2 Runtime이 필요합니다. 설치 파일은 앱, 다운로드 보조 실행 파일, 글꼴을 사용자 계정의 프로그램 폴더에 설치합니다. 현재 설치 파일에는 코드 서명이 없어 Windows에서 게시자를 확인할 수 없다고 표시할 수 있습니다.

`main` 브랜치에 새 커밋을 올리면 GitHub Actions가 의존성 취약점 검사, Windows 설치 파일 빌드, SHA-256 체크섬 생성 후 최신 Release를 갱신합니다. 설치된 앱의 자동 업데이트 기능은 아직 없으므로 새 버전은 최신 설치 파일을 실행해 덮어 설치합니다. [빌드 파이프라인](.github/workflows/windows-installer.yml)과 [설치 스크립트](installer.iss)를 저장소에서 확인할 수 있습니다.

소스에서 직접 실행하려면 아래의 `run.bat` 안내를 따르세요. Microsoft Store Python으로 실행한 기존 작업 기록은 설치판 첫 실행 때 로컬 저장소로 가져옵니다. 로그인 세션은 옮기지 않으므로 설치판 브라우저에서 다시 로그인해야 할 수 있습니다.

### 개발 및 로컬 빌드

```powershell
python -m pip install -r requirements-build.txt
python -m pip_audit -r requirements.txt --strict
./build.ps1
```

Inno Setup 6이 설치되어 있어야 합니다. 생성된 파일은 `dist/installer/XMediaSaverSetup.exe`입니다. 작업 기록과 X 쿠키가 들어 있는 사용자 데이터 폴더는 Git에 포함하지 않습니다.

`run.bat`을 더블클릭하면 **내장 X 브라우저가 있는 Windows 앱**이 열립니다. 대시보드, 로컬 작업 목록, 미디어 갤러리, 설정 화면을 제공합니다. Windows의 앱 색 설정에 따라 창과 팝업이 라이트·다크 모드로 바뀝니다. XBD 서비스·계정·클라우드와 연결되지는 않습니다.

## 데스크톱 앱 사용

1. Python 3.11 이상을 설치하고 `run.bat`을 실행합니다. 첫 실행에는 `gallery-dl`과 PySide6를 설치하므로 인터넷이 필요합니다.
2. **X 브라우저**에서 X에 로그인합니다. 로그인 화면은 앱 안에서 열리며 X 비밀번호를 프로그램 자체에 입력하지 않습니다. 브라우저에서 계정 프로필을 열면 상단에 `@아이디`, 게시물을 열면 게시물 링크가 자동 입력됩니다.
3. 계정 URL, 게시물 링크 또는 `@아이디`를 입력하고 **미디어 확인**을 누릅니다. 목록은 백그라운드에서 불러오며 진행 개수를 표시합니다. 다운로드 전에 사진·영상 목록, 계정 이름과 프로필 사진, 이미 저장한 항목을 확인합니다.
4. **새 미디어 자동 선택**을 켜면 기존 다운로드 기록에 없는 항목을 선택합니다. 항목별 체크박스로 선택을 바꾸고 **선택한 미디어 다운로드**를 누릅니다.
5. **로컬 작업**에서 미디어를 열거나 작업 메뉴로 목록을 새로 확인하고 다운로드를 관리합니다. 작업 상세에서 카드·목록 보기와 완료·미저장 상태를 확인합니다. 대시보드에는 최근 저장한 사진과 영상 썸네일이 표시됩니다.

**X 브라우저는 하나만 사용합니다.** Windows Edge WebView2에서 X 로그인과 영상 재생을 모두 진행하며, 다운로드할 때 같은 브라우저의 로그인 쿠키를 읽습니다. 처음 실행할 때 이전 버전의 앱 브라우저 로그인 세션이 남아 있으면 한 번 가져옵니다.

세션 확인에는 앱 실행 중 `127.0.0.1`의 임시 포트를 사용합니다. 로그인 쿠키 값은 앱 화면이나 로그에 표시하지 않고 다운로드 작업용 임시 파일로만 전달합니다.

다운로드 위치와 **폴더·파일 이름 템플릿**은 설정에서 바꿀 수 있습니다. 템플릿 입력칸 아래의 항목 버튼을 누르면 이름 변수가 삽입되고 예시 결과를 볼 수 있습니다. 파일 확장자는 자동으로 붙고, 파일명이 겹치지 않도록 게시물·미디어 번호가 필요하면 자동으로 추가됩니다. 변경한 템플릿은 새 작업에 적용되며 기존 작업의 저장 경로는 유지됩니다.

작업 기록은 `%LOCALAPPDATA%/XMediaSaver/jobs.json`, 내장 브라우저의 로그인 데이터는 `%LOCALAPPDATA%/XMediaSaver/XMediaSaver/WebView2`에 저장됩니다. 작업용 쿠키 파일은 임시로 만들고 작업이 끝나면 삭제합니다. 로그인 세션이 남아 있는 PC 계정은 다른 사람과 공유하지 마세요.

X에서 접근할 수 없는 비공개·삭제된 게시물이나 X가 제공하지 않는 오래된 게시물까지 전부 저장되지는 않습니다. X 사이트의 변경에 따라 `gallery-dl`을 업데이트해야 할 수도 있습니다. 구독료나 자체 다운로드 수량 제한은 없습니다.

예전 단순 창 버전은 `run-classic.bat`으로 열 수 있습니다.

## 예전 단순 창 버전

X 계정의 미디어 게시물에서 사진과 영상을 PC에 저장하는 Windows 프로그램입니다. 구독료나 자체 다운로드 개수 제한은 없습니다. 실제 접근 가능 범위와 속도는 X의 로그인, 비공개 계정, API 제한에 좌우됩니다.

## 실행

1. Python 3.11 이상을 설치합니다.
2. `run-classic.bat`을 더블클릭합니다. 첫 실행에는 `gallery-dl`을 설치하므로 인터넷이 필요합니다.
3. `@아이디`, `아이디`, `https://x.com/아이디` 중 하나를 입력합니다.
4. **로그인 브라우저**를 `프로그램 전용 Chrome`으로 두고 **X 로그인 열기**를 누릅니다. 새로 열린 Chrome 창에서 X에 로그인합니다. 이 창은 열어 두세요.
5. 계정을 입력하고 **로그인·접근 확인**을 누릅니다. `접근 확인됨`이 표시되면 저장 폴더를 고르고 **저장 시작**을 누릅니다.

`프로그램 전용 Chrome`은 별도 브라우저 프로필을 사용합니다. 창이 열린 상태에서도 로그인 세션을 확인할 수 있습니다. X 비밀번호는 Chrome의 X 로그인 화면에만 입력하며 프로그램에는 입력하지 않습니다. 전용 프로필은 Windows 사용자 폴더의 `AppData/Local/XMediaSaver/ChromeProfile`에 유지되어 다음 실행에도 로그인을 재사용할 수 있습니다. 다운로드 과정에 필요한 쿠키는 임시 파일로 전달하고 작업이 끝나면 삭제합니다.

기존 Chrome, Edge, Firefox, Brave 로그인 세션을 선택하는 방식도 남겨 두었습니다. 다만 이 PC에서는 기존 Chrome의 쿠키 복호화가 실패했습니다. 이 경우 전용 Chrome을 사용하세요. 또는 X 쿠키를 Netscape 형식의 `cookies.txt`로 내보내 선택할 수 있습니다. 쿠키 파일은 로그인 세션과 같으므로 타인에게 공유하지 마세요.

**로그인·접근 확인**은 입력한 계정의 미디어 한 건을 다운로드 없이 조회합니다. 성공하면 해당 계정의 미디어에 접근할 수 있다는 뜻입니다. X의 로그인 계정 이름이나 비밀번호를 표시하는 기능은 아닙니다. X의 응답이 늦으면 45초 후 확인을 중단합니다.

파일은 선택한 저장 폴더의 `계정아이디` 하위 폴더에 들어갑니다. 같은 계정을 다시 실행하면 다운로드 기록을 이용해 이미 받은 파일을 건너뜁니다. `중단` 후 재시작해도 이어서 받을 수 있습니다. 리포스트의 미디어는 기본적으로 제외합니다.

이 프로그램은 공개되었거나 사용자의 로그인 계정으로 접근 가능한 게시물만 저장합니다. 삭제된 게시물, 접근 권한이 없는 비공개 게시물, X가 타임라인에 제공하지 않는 오래된 게시물은 내려받을 수 없습니다. 다운로드한 콘텐츠는 권리자의 권리를 존중해 사용하세요.
