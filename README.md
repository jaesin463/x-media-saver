# X 미디어 저장기

**X 계정과 게시물의 사진·영상을 살펴보고, 원하는 항목만 PC에 저장하는 Windows 앱입니다.**

앱 안의 브라우저에서 X에 로그인하고 계정 URL, 게시물 링크 또는 `@아이디`를 입력하세요. 미디어 목록을 먼저 확인한 뒤 저장할 항목을 선택할 수 있습니다. 자체 구독료나 다운로드 개수 제한은 없습니다.

[Windows 설치 파일 다운로드](https://github.com/jaesin463/x-media-saver/releases/latest/download/XMediaSaverSetup.exe)

## 주요 기능

### 앱 안에서 로그인하고 탐색

내장 X 브라우저에서 로그인, 계정 탐색, 영상 재생을 한곳에서 할 수 있습니다. 브라우저에서 계정이나 게시물을 열면 해당 아이디 또는 게시물 링크가 다운로드 입력칸에 자동으로 채워집니다. X 비밀번호를 앱의 별도 입력창에 적을 필요는 없습니다.

### 다운로드 전 미디어 확인

**미디어 확인**을 누르면 사진과 영상 목록을 불러옵니다. 계정 이름과 프로필 사진, 미디어 썸네일, 저장 상태를 확인하고 카드에서 원하는 항목을 선택한 뒤 다운로드를 시작하세요. 목록을 불러오는 동안에도 앱을 사용할 수 있습니다.

게시물 링크를 입력한 경우에는 목록 확인을 거치지 않고 **다운로드** 버튼으로 바로 저장할 수도 있습니다. 다운로드 중에도 내장 브라우저를 계속 탐색할 수 있습니다.

### 새 미디어만 이어서 저장

같은 계정을 다시 불러올 때 **새 미디어 자동 선택**을 켜면 기존 다운로드 기록에 없는 항목을 선택합니다. 이미 저장한 항목과 아직 저장하지 않은 항목을 구분해 볼 수 있습니다.

### 작업과 파일을 한곳에서 관리

대시보드에서 최근 작업과 저장한 미디어를 확인하고, **로컬 작업**에서 계정별 다운로드 상태를 관리할 수 있습니다. 작업 상세 화면은 카드 보기와 목록 보기를 지원하며 이미지·동영상 및 저장 상태로 목록을 좁혀 볼 수 있습니다.

### 내 방식대로 저장

설정에서 저장 폴더와 **폴더 이름·파일 이름 템플릿**을 지정할 수 있습니다. 계정명, 게시물 시간 등의 항목을 템플릿에 넣고 예시 파일명을 확인하세요. 앱은 Windows의 라이트·다크 모드를 따르며, 글자 크기를 5단계로 조절할 수 있습니다.

## 시작하기

1. [최신 설치 파일](https://github.com/jaesin463/x-media-saver/releases/latest/download/XMediaSaverSetup.exe)을 내려받아 실행합니다.
2. 앱의 **X 브라우저**에서 로그인합니다.
3. 계정 URL, 게시물 링크 또는 `@아이디`를 입력합니다.
4. **미디어 확인**으로 목록을 열고 저장할 항목을 선택합니다.
5. **선택한 미디어 다운로드**를 누릅니다. 게시물 링크는 **다운로드** 버튼으로 바로 저장할 수도 있습니다.

Windows 10/11 x64와 Microsoft Edge WebView2 Runtime이 필요합니다.

## 이용 범위와 데이터

이 앱은 로그인한 계정으로 접근할 수 있는 X 미디어를 저장합니다. 삭제된 게시물, 접근 권한이 없는 비공개 게시물, X가 제공하지 않는 오래된 게시물은 저장할 수 없습니다. 다운로드한 콘텐츠는 권리자의 권리를 존중해 사용하세요.

작업 기록과 로그인 세션은 사용자 PC에 저장됩니다. X 로그인 비밀번호를 앱이 별도로 수집하지 않으며, 다운로드에 필요한 쿠키 파일은 작업 중 임시로 사용한 뒤 삭제합니다. 클라우드 계정이나 저장 공간은 필요하지 않습니다.
